# 서브컬쳐 미소녀 픽셀 캐릭터 액션 벤치마크

Claude Opus 5.5가 동일한 마법검사 캐릭터와 애니메이션 명세를 세 가지 캐릭터 기준 크기로 표현한 결과를 비교합니다. 비교 변수는 설계 크기와 그에 맞춘 기준 등신대 하나이며, 자동으로 승자를 선정하지 않습니다.

- 모델: `claude-opus-5.5`
- 추론 수준: `high`
- [라이브 비교 페이지](https://legerdo.github.io/opus55-anime-pixel-character-action-benchmark-20260929-032231/)

## 크기와 캔버스

캐릭터 기준 설계 영역은 기본 자세와 픽셀 밀도를 정합니다. 프레임 캔버스는 투명 여백과 무기·마법 효과가 움직일 공간을 포함하며, 설계 영역을 확대해서 채우지 않습니다.

| Variant | 캐릭터 기준 설계 영역 | 기준 등신대 | 프레임 캔버스 | 발 기준선 |
| --- | ---: | ---: | ---: | ---: |
| S | 48×64 px | 약 2.5–3등신 SD | 84×96 px | y=80 |
| M | 64×96 px | 약 3.5–4등신 Semi-SD | 112×144 px | y=120 |
| L | 80×112 px | 약 4.5–5.5등신 | 140×168 px | y=140 |

## 캐릭터와 애니메이션

세 결과 모두 은발 양갈래 트윈테일, 또렷한 눈동자 하이라이트, 분홍 리본이 달린 네이비 코트와 플리츠 스커트, 긴 스카프, 롱부츠, 레이피어를 가진 3/4 시점의 미소녀 마법검사 모험가를 목표로 합니다. 현대 인디 애니메이션 픽셀 아트 스타일로 밝은 팔레트, 명확한 셀 셰이딩, 부위별 소프트 외곽선과 보조 움직임을 표현합니다.

각 결과는 투명 캔버스 기반의 20프레임을 제공합니다.

- Idle: 2프레임, 프레임당 500 ms
- Run: 6프레임 루프, 프레임당 90 ms
- Attack A: 6프레임 일회성 베기/찌르기, 프레임당 100 ms
- Attack B: 6프레임 일회성 캐스팅 및 검기 방출, 프레임당 100 ms

웹 미리보기에서는 일회성 공격의 마지막 프레임 뒤 400 ms 쉰 다음 반복합니다. 비교 페이지에서 각 결과를 실시간 미리보기, contact sheet, 원본 1×, 캐릭터 표시 높이를 맞춘 확대 샘플로 확인할 수 있습니다.
