현재 작업 폴더가 유일한 작업 영역이다. 파일 읽기와 쓰기, 임시 브라우저 프로필과 스크린샷은 모두 이 폴더 안에서만 처리한다. parent·sibling 폴더, 다른 run·세션·prompt·결과·스크린샷은 열거나 참고하지 않는다. 이전 대화나 작업을 복원하지 않는다.

### [캐릭터 디자인 명세: 서브컬쳐 미소녀 마법검사]
캐릭터는 생동감 있고 귀여운 인상의 **미소녀 판타지 마법검사 모험가**다. 
- **헤어 & 얼굴:** 화사한 은발(Silver Hair)에 풍성한 양갈래 트윈테일, 정수리의 매끄러운 빛 반사(엔젤링 픽셀), 또렷하고 커다란 호박색/루비색 눈동자(눈동자 내부 하이라이트 픽셀 포함), 귀여운 미소녀 표정.
- **의상 & 액세서리:** 가슴에 분홍색 리본 장식이 달린 다크 네이비 제복風 코트, 프릴 플리츠 스커트, 바람에 날리는 긴 스카프, 어두운 가죽 롱부츠, 손가락이 드러나는 가죽 장갑.
- **무기 & 전투 스타일:** 한손에 쥐 날렵한 마법검(레이피어), 검에 서리는 cyan/pink 빛의 마력 에테르 이펙트.
- **시점:** 전신이 보이는 약간 오른쪽을 향한 3/4 시점으로 그린다.

### [서브컬쳐 픽셀 아트 스타일 가이드 (Anime Pixel Art Principles)]
스타일은 **Polished Modern Anime Indie Pixel Game Character**다.
1. **눈(Eye)과 이목구비 강조:** 서브컬쳐 캐릭터의 핵심은 눈이다. 가장 작은 S 규격에서도 최소 1~2px의 눈동자 하이라이트를 명확히 배치하고, M과 L 규격에서는 눈꺼풀 라인과 눈동자 명암을 2단계 이상 표현하여 시선과 표정이 1× 해상도에서 또렷이 읽혀야 한다. 정면 얼굴을 옆으로 선 몸에 붙이지 말고 코와 턱, 눈의 크기 차이로 3/4 시점의 입체감을 형성한다.
2. **화사한 팔레트 & 셀 셰이딩 (Cel Shading):** 칙칙하고 어두운 톤이나 과도한 디더링(점찍기 명암)을 피하고, **2~3단계의 명확한 덩어리 음영**을 사용한다. 피부, 머리카락, 옷감의 색상이 밝고 또렷하게 대비되도록 한다.
3. **소프트 외곽선 (Selective Outlining):** 캐릭터 전체를 둔탁한 순흑색(#000000)으로 둘러싸지 않는다. 피부는 살구색 어두운 톤, 은발은 어두운 회보라색, 옷은 딥 네이비 등 **각 부위의 바탕색보다 한 단계 어두운 톤의 외곽선**을 사용하여 부드럽고 2D 일러스트 같은 완성도를 만든다.
4. **보조 애니메이션 (Secondary Motion):** 대기(Idle)와 이동, 공격 동작 시 캐릭터의 머리카락(트윈테일), 치마 자락, 스카프가 몸의 움직임에 맞춰 자연스럽게 따라 흔들리는 프레임을 넣어야 한다.

제작 순서는 Idle의 전신 실루엣과 얼굴 방향, 눈동자 하이라이트를 먼저 확정하고, 달리기와 두 공격의 준비·주동작·회복 핵심 포즈를 잡은 다음 중간 프레임과 트윈테일·스커트·스카프의 후행 움직임을 채운다. 머리, 목, 어깨, 팔꾼치, 손, 골반, 무릎, 발의 위치 관계를 먼저 맞추고 장식은 마지막에 더한다. 손은 팔 끝에 연결되고 검은 손의 그립에서 시작해야 한다. 한 프레임에서 다른 프레임으로 갈 때 관절이나 몸통이 갑자기 끊기거나 튀지 않아야 한다.

정확히 다음 20프레임을 만든다.

- **Idle (2프레임):** 기준 자세에서 미세한 호흡과 함께 눈 깜빡임(Blink) 또는 트윈테일과 치마 자락의 가벼운 살랑임이 보인다.
- **Run (6프레임 루프):** 좌우 팔·다리의 교대 리듬이 분명하고, 역동적인 달리기에 맞춰 트윈테일과 치마 자락, 스카프가 뒤로 흩날리는 후행 움직임이 있다.
- **Attack A (6프레임 일회성):** 날렵한 검 베기 또는 찌르기. 준비 → 타격 → 후속 동작의 순서가 명확하며, 검을 휘두르는 순간 화려한 cyan/pink 궤적 잔상 이펙트가 발생한다.
- **Attack B (6프레임 일회성):** 마력 캐스팅 후 검기 방출. 검을 치켜세우는 캐스팅 제스처 후 전방으로 cyan/pink 마력 파동을 날린다. 이펙트가 캐릭터의 귀여운 얼굴이나 주 실루엣을 완전히 가리지 않는다.

재생 간격은 Idle 프레임당 500 ms, Run 프레임당 90 ms, Attack A와 Attack B 프레임당 100 ms다. 두 공격은 일회성 애니메이션으로 만들고, 웹 미리보기에서만 마지막 프레임 뒤 400 ms를 쉬 다음 처음부터 다시 보여준다.

Run과 두 Attack은 실제로 구분되는 포즈의 연속이어야 한다. Run에서는 지면을 딛는 발과 들린 발을 구분하고, 발 접촉·골반의 이동·어깨의 반대 회전·팔의 교대 움직임으로 체중 이동을 표현한다. 발이 지면에서 미끄러지는 것처럼 보이지 않게 한다. Attack A는 팔만 돌리지 말고 상체와 골반의 준비·회전·회복을 검 궤적과 연결한다. Attack B의 마력 파동은 검 끝에서 발생해야 한다. 같은 그림의 단순 위치 이동이나 이펙트 교체만으로 프레임 수를 채우지 않는다. 애니메이션 중 캐릭터 자체가 갑자기 커지거나 줄어들지 않게 한다. 필요하면 무기 궤적과 마법 효과가 넓어진 캔버스 여백을 쓰되, 몸의 기준 크기를 유지한다.

1× 포즈 가독성, 서브컬쳐 캐릭터 정체성(눈/머리 표현), 무기와 팔의 분리, 재질 구분을 우선한다. 작은 설계 영역에서는 미세 묘사보다 명확한 픽셀 덩어리와 동작을 우선한다. 여유가 생기는 해상도에서는 의미 있는 재질과 후행 움직임만 추가한다.

각 제작 세션은 자기 폴더에 단일 index.html만 결과물로 만든다. Vanilla JavaScript와 Canvas 2D를 사용하고 모든 픽셀 그림을 코드로 직접 제작한다. 외부 이미지·SVG·sprite sheet·font·라이브러리·네트워크 요청은 금지한다. 캔버스 배경은 투명하며 페이지의 체크무늬 배경은 캔버스 바깥 CSS로 표현할 수 있다. 모든 논리 좌표와 최종 그리기 좌표는 정수다. imageSmoothingEnabled=false와 image-rendering: pixelated를 적용하고 anti-aliasing, blur, shadowBlur, subpixel drawing을 사용하지 않는다.

각 페이지에는 Idle, Run, Attack A, Attack B 실시간 미리보기, 20프레임 전체 contact sheet, 원본 1× 샘플, 동일한 캐릭터 표시 높이로 확대한 샘플을 넣는다. 모든 프레임 원본 캔버스의 intrinsic width/height는 자기 variant 명세의 프레임 캔버스 값이어야 한다. 비교 확대 샘플도 같은 원본 캔버스를 사용하며 캐릭터 기준 높이를 약 384 CSS px, 전체 프레임 높이를 576 CSS px로 표시한다. 전체 프레임 표시 폭은 자기 variant 명세에 지정된 값을 쓴다. 확대율이 정수가 아닌 경우에도 최종 CSS 크기와 렌더 대상 좌표는 정수로 맞추고 nearest-neighbor로만 확대한다.

외부 검증을 위해 네 미리보기에는 data-animation-preview 값 idle, run, attack-a, attack-b를 붙이고, contact sheet의 프레임에는 data-contact-frame 값 idle:0부터 해당 애니메이션의 마지막 index까지 붙인다. animation-preview, idle-preview, run-preview, attack-a-preview, attack-b-preview, contact-sheet, native-size-example, equal-display-size-example ID를 제공한다.

첫 완성본을 만든 뒤 자기 폴더만 제공하는 로컬 HTTP 서버로 실제 브라우저 렌더를 확인한다. HTTP 로드, JavaScript 오류, 외부 요청, 2/6/6/6 프레임 수, 모든 원본 캔버스 크기, 투명 alpha, 비어 있지 않은 그림, 중요한 부분의 잘림을 확인한다. 자기 폴더 안에 스크린샷과 브라우저 프로필을 저장한다. Idle 얼굴을 1×와 확대 화면에서 보고 미소녀 이목구비, 눈동자 하이라이트, 트윈테일 헤어 형태, 목과 어깨 연결, 서브컬쳐 셀 셰이딩 톤을 확인한다. Contact sheet와 실제 재생에서 발 접촉, 체중 이동, 스커트/머리카락의 후행 흔들림, 공격의 준비·타격·회복을 확인한다. 구조 검사를 통과해도 얼굴이나 동작이 어색하면 완성으로 판단하지 않는다. 명백한 시각 문제는 동일한 조건으로 최대 두 차례 집중 수정하고 다시 확인한다. 목표 품질에 못 미치면 그 한계를 보고한다. 설치나 다운로드 없이 이용 가능한 브라우저 도구를 사용하고, 확인 후 임시 HTTP 서버와 브라우저를 종료한다.

L 세션에만 전달: 캐릭터 기준 설계 영역 80×112 px (약 4.5~5.5등신 고등신 미소녀), 전체 프레임 캔버스 140×168 px. 좌우 여백 각 30 px, 위아래 여백 각 28 px, 발 기준선 y=140이다. 비교 확대 샘플의 전체 프레임 표시 크기는 480×576 CSS px다.
